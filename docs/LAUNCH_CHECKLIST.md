# Launch-day checklist and first update plan (draft)

Claude never submits or publishes. The owner does the steps marked (owner).

## One week before
- [ ] `npm run check`, `npm run flavours`, `npm run e2e` all green on `main`.
- [ ] Name is free in both stores and on Google (owner).
- [ ] Privacy policy is online and its link is in both stores (owner).
- [ ] Store texts and screenshots uploaded; languages checked by native speakers (owner).
- [ ] Real AdMob and RevenueCat ids are in; a test purchase, restore and a test ad were tried on real phones (owner + Claude).
- [ ] Google Play 14-day closed test with 12 testers is done (owner).
- [ ] CrazyGames preview and Poki Inspector report no problems (owner).

## Launch day
1. Upload the release builds: web zips, Android bundle, iOS archive (owner).
2. Check the live pages open and the game starts and plays level 1.
3. Post the first clip (see `POSTING_CHECKLIST.md`) (owner).
4. Watch store reviews and crash reports; answer kindly within a day.
5. Do not change prices or ad rules in the first week.

## First update plan (about 2 weeks after launch)
- Fix the top crash or confusing level seen in reviews and analytics.
- Retune levels with a high fail rate; keep every solution test green.
- Add World 5 when a spring mechanic is found.
- Add native-speaker fixes for texts.
