# Owner checklist for posting

Claude never posts or signs up for anything. This is the list for you. Tick as you go.

## Before the first post
- [ ] Decide the public name (check app stores and Google for clashes).
- [ ] Make accounts: TikTok, YouTube, Instagram (same name on all).
- [ ] Put `docs/PRIVACY_POLICY.md` on a web page and note the link.
- [ ] Run `npm run build && npm run shots` and `npm run trailer`; the files appear in `store-shots/` and `trailer-clips/`.

## Clips (vertical or wide)
- [ ] Cut 15–30 second clips from `trailer-clips/`: build, press GO, car crosses (or the bridge falls: both are fun).
- [ ] Hook in the first 2 seconds, for example "Can this bridge hold a truck?".
- [ ] Add a text on screen with the budget, and end with "Can you do it cheaper?".
- [ ] Add the game link or store name in the caption.

## Post ideas (one a day for the first week)
1. Failed bridge, funny collapse.
2. 3-star cheap bridge vs. a big costly one.
3. Drawbridge opening for the ship.
4. Rope level: "only ropes!".
5. Daily Bridge: invite people to share their streak.
6. Level editor: show a bridge code and ask people to try it.
7. Thank-you post with the best comments.

## Hashtags
`#bridgeit #physicspuzzle #indiegame #gamedev #puzzlegame #mobilegame #bridgebuilder`

## Rules
- Reply to comments kindly; no paid promotion without telling Claude first (costs money).
- Do not promise dates. Say "coming soon" until the store page is live.
- Never share your account passwords or store keys in chat.

## After posting
- [ ] Tell Claude which clip did best, and what players say, so the next update can fix it.
